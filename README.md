# Free Email Signature Generator

Client-side HTML email signature builder for [free-email-signature-generator.web-free.site](https://free-email-signature-generator.web-free.site).

Based on [clarkemedia/email-signature-generator](https://github.com/clarkemedia/email-signature-generator) (MIT) by Eoin McMahon / Clarke Media.

## Build

```bash
python3 build.py
```

Output is written to `dist/` for Cloudflare Workers static assets (`wrangler.toml`).
